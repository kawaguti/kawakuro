# kawakuro

打ち込んだ文を、Discordのボイスチャンネルで声にするBotです。声は VOICEVOX で作ります。PCで起動しておくだけで動きます。

使い方は2つあります。

- **分身**：喉を痛めて声が出せないときなどに、あなたが打った文を代わりに喋る
- **受付インターホン**：テキストチャンネルでBotにメンションすると、ボイスチャンネルでチャイムを鳴らして読み上げる。受付の人が画面を見ていなくても、来た人の連絡に音で気づける（下の「受付モード」）

受付インターホンだけを試したい人には、1ファイルで動く最小版 [examples/reception-minimal.js](examples/reception-minimal.js) があります。

VOICEVOX の声は、キャラクターごとに利用規約とクレジット表記が決まっています。使う前に、下の「クレジット」を読んでください。

## できること

- あなたがボイスチャンネルに入ると、Botも自動でついてくる（出ると一緒に出る）
- そのボイスチャンネル内のチャットにあなたが書いた文を、声で読み上げる
- 指定したテキストチャンネルへの投稿も読み上げる（Muse経由の投稿用）
- 読み上げるのは、あなたと、許可した投稿者の文だけ
- `dict.json` に書いた固有名詞は、指定した読みで読む

## 準備（最初の1回だけ）

### 1. Discord側でBotを作る

1. https://discord.com/developers/applications を開き、「New Application」で作成する（名前が分身の名前になります）
2. 左の「Bot」を開き、「Reset Token」でトークンを発行して控える
3. 同じページの **Message Content Intent をオンにする**（これがないと文を読めません）
4. 左の「OAuth2」→「URL Generator」で次を選ぶ
   - Scopes：`bot` と `applications.commands`
   - Bot Permissions：`View Channels`、`Connect`、`Speak`、`Read Message History`
5. できたURLを開いて、自分のサーバーに招待する

### 2. PC側の準備

1. VOICEVOX（https://voicevox.hiroshiba.jp/）をインストールして起動する
2. Node.js 22.12 以上（https://nodejs.org/）をインストールする
3. このフォルダで次を実行する

```
npm install
```

### 3. 設定ファイルを作る

`.env.example` をコピーして `.env` という名前にし、上の3つを埋めます。

| 項目 | 入れるもの |
|---|---|
| `DISCORD_TOKEN` | 手順1で控えたトークン |
| `GUILD_ID` | サーバーのID |
| `OWNER_USER_ID` | あなたのユーザーID |

IDは、Discordの「設定 → 詳細設定 → 開発者モード」をオンにすると、右クリック（スマホは長押し）の「IDをコピー」で取れます。

## 使い方

VOICEVOXを起動した状態で、次を実行します。

```
npm start
```

「VOICEVOXに接続できました。声は No.7（アナウンス）です。」と出たら準備完了です。
あとはボイスチャンネルに入り、そのチャンネルのチャットに文を打つだけです。

| コマンド | 動き |
|---|---|
| `/join` | あなたのいるボイスチャンネルに呼ぶ（自動でついてこないとき用） |
| `/leave` | 退出させる |
| `/skip` | 読み上げを止める |
| `/say text:文` | チャットに残さずに喋らせる |

止めるときは、実行中の画面で Ctrl+C を押します。

## 複数のサーバーで使う

`.env` の `GUILD_ID` にサーバーIDをカンマ区切りで並べます（例：`GUILD_ID=111,222`）。

- あなたがどれかのサーバーのボイスチャンネルに入ると、Botもそこへついていきます。別のサーバーのボイスチャンネルに移れば、Botも移ります
- `TEXT_CHANNEL_ID` のチャンネル（自分のサーバーの読み上げ専用チャンネルなど）に書いた文は、Botがいまいるボイスチャンネルで読み上げます。どのサーバーのボイスチャンネルにいても同じです
- スラッシュコマンドは、並べたすべてのサーバーで使えます

## 受付モード（メンションを読み上げる）

受付の人がテキストを見続けなくても、来た人の連絡に音で気づけるようにするモードです。
`.env` に `MODE=reception` と書くと、受付モードで動きます。

- Botは `RECEPTION_VOICE_CHANNEL_ID` のボイスチャンネルに居続けます。切れても30秒以内に入り直します
- `RECEPTION_TEXT_CHANNEL_IDS` のチャンネル（と、そのボイスチャンネル内のチャット）で **Bot宛てにメンション**された文を、誰のものでも読み上げます
  - 例：`@kawakuro いま1階に着きました` →（チャイム）「たなかさんから。いま1階に着きました」を2回
- 読み終えると、そのメッセージに ✅ を付けます
- 同じ人が続けて呼べるのは `RECEPTION_COOLDOWN_SEC` 秒に1回です。早すぎる呼び出しや、待ちが5件を超えた分には ⏳ を付けて読みません
- 受付側は、PCかスマホのDiscordでそのボイスチャンネルに入り、スピーカーから音が出るようにしておきます
- `/leave` で退出させると、`/join` するまで戻りません
- 起動して受付のボイスチャンネルに入ると、受付のテキストチャンネルに「使い方」と「声のクレジット」を書きます。止めるときは「失礼します。」と書きます。`RECEPTION_NOTICE=false` で書かなくなります
- Bot本人へのメンションのほか、Botと同じ名前の「Botのロール」へのメンションも呼び出しとして読みます（入力候補で選び間違えやすいため）
- 返信（リプライ）で自動的に付くメンションは読みません。返信の本文に自分でメンションを書いた場合は読みます
- 時刻を決めて喋らせたいときは、フォルダに `announce.txt` を作り、`18:30 あと5分です` のように1行ずつ書きます。その時刻（PCの時計、当日ぶん）に受付の声で読み、読んだ行は消えます。時刻の無い行はすぐ読みます
- メンションからも予約できます。`@Bot 18:30 あと5分です` のように、先頭に時刻、空白をはさんで文を書くと、投稿に 🕒 が付き、その時刻に読みます（`18時30分`、`18時半`、全角の数字も可。今日のこれからの時刻だけ）。同じ時刻に同じ文が重なったら、1回だけ読みます
- クレジットは声の名前から自動で作ります（例：`VOICEVOX:ずんだもん、VOICEVOX:No.7`）。もち子さんのように書き方が決まっている声は、`RECEPTION_CREDIT` に規約どおりの表記を書きます

受付をやめるときは `MODE=` を空にして、Botを起動し直します。

### 入力は2系統、喋る先は1つ

受付モードのあいだ、Botが喋るのは受付のボイスチャンネルだけです。そこへ、2つの入り口から文が届きます。

- **受付のチャンネルでのメンション**：誰でも。チャイムのあと、名前付きで2回読みます
- **`TEXT_CHANNEL_ID` のチャンネルへの投稿**（別のサーバーでもよい）：あなたと、`ALLOWED_AUTHOR_IDS` の投稿者（Museなど）だけ。メンション不要で、チャイムなしで1回読みます

受付モードのあいだは、あなたがほかのボイスチャンネルに入っても、Botはついていきません。

2つの入り口で声を分けられます。`RECEPTION_VOICEVOX_SPEAKER` に書いた声がメンションの呼び出し用、`VOICEVOX_SPEAKER` が `TEXT_CHANNEL_ID` への投稿用です。声が違うと、呼び出しかどうかを耳で聞き分けられます。

## このPCとノートPCで使う（Dropbox同期）

- `start.cmd` をダブルクリックすると起動します。`node_modules` が無いPC（ノートPCの初回）では、先に `npm ci` を自動で実行します
- `node_modules` は Dropbox の同期対象外にしてあります（PCごとに中身が違うため）。`.env` と `dict.json` は同期されるので、設定と辞書は両方のPCで共通です
- **Botを動かすのは同時に1台だけ**にしてください。2台で起動すると二重に喋ります
- どちらのPCにも VOICEVOX と Node.js 22.12 以上が必要です

## 声を変える

初期設定は「No.7／アナウンス」（女性のナレーション風）です。

```
npm run voices
```

で選べる声の一覧が出ます。`.env` の `VOICEVOX_SPEAKER` に、`春日部つむぎ/ノーマル` のような「名前/スタイル」か、番号を書いて、Botを起動し直します。速さは `VOICEVOX_SPEED`（1.0が標準）で変えられます。

## 読み方を直す

`dict.json` に「表記」と「読み」を足して、Botを起動し直します。

```json
{
  "RSGT": "アールエスジーティー",
  "川口": "かわぐち"
}
```

## Museから喋らせる

Museに打った文をDiscordに投稿させ、それをこのBotが読む形にします。

1. 読み上げ専用のテキストチャンネルを作り、そのIDを `.env` の `TEXT_CHANNEL_ID` に書く
2. MuseにDiscord用のコネクタを追加し、「ーーで始まる文は、そのチャンネルにそのまま投稿する」と指示しておく
3. Museの投稿者を許可する
   - コネクタが別のBotやWebhookで投稿する場合：そのIDを `ALLOWED_AUTHOR_IDS` に書く
   - この分身Botのトークンで投稿させる場合：`READ_OWN_MESSAGES=true` にする

文頭の「ーー」は読み上げ時に自動で外れます。

Botトークンを外部のコネクタサービスに預けると、そのサービスがBotとして投稿できるようになります。預ける場合は、このBotを入れるサーバーを自分のサーバーだけにしておくと安心です。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 起動時に「ログインできません」 | トークンの貼り間違い、Message Content Intent がオフ |
| ボイスチャンネルに入ってこない | Botに「接続」「発言」の権限があるか。`/join` も試す |
| 入るが喋らない | VOICEVOXが起動しているか。Discord側でBotの音量が0やミュートになっていないか |
| 打っても反応しない | 打った場所が、Botのいるボイスチャンネルのチャットか `TEXT_CHANNEL_ID` のチャンネルか |

## クレジット

VOICEVOX の声には、キャラクターごとに権利者がいます。クレジットの書き方も、商用・非商用でどこまで使えるかも、声ごとに個別に決まっています。

- 声を人に聞かせるときは、「VOICEVOX:ずんだもん」のようなクレジット表記が必要です。書き方は声ごとに違います（例：もち子さんは `VOICEVOX:もち子(cv 明日葉よもぎ)`）
- 商用でも使える声と、個人の非商用に限られる声があります。企業が関わる場で使うなら、商用可と明記された声を選んでください
- 規約は、VOICEVOX アプリで各キャラクターを選ぶと表示されます。変わることがあるので、使う前に自分で確かめてください

受付モードでは、起動時に受付のテキストチャンネルへクレジットを書きます。サーバーの説明やBotの自己紹介にも書いておくと確実です。
